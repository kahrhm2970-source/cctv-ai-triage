# CCTV AI Triage | مساعد فرز أوصاف أعطال الكاميرات
الحسين علي أبو طالب — Alhussin Ali Abutalib

مشروع تعليمي أُعد بمساعدة الذكاء الاصطناعي، يربط CCTV Operations والدعم الفني بتعلم الآلة. يصنف **الوصف النصي** إلى اتصال، تسجيل، جودة صورة، أو مراجعة بشرية. لا يحلل الفيديو أو يشخص السبب الجذري.

## تشغيل محلي بدون مفاتيح أو اشتراكات
Python 3.10+، المكتبة القياسية فقط:
```sh
python triage.py
python triage.py "فشل استرجاع التسجيلات القرص ممتلئ"
python evaluate.py
python -m unittest discover -s tests -v
```
يدخل المستخدم وصفًا افتراضيًا؛ الأداة لا تتصل بأي جهاز أو API ولا تحفظ المدخلات. استخدام وسيط سطر الأوامر قد يسجله في shell history؛ استعمل الإدخال التفاعلي مع بيانات افتراضية فقط.

## أين الذكاء الاصطناعي؟
مصنف Naive Bayes يتعلم تكرارات الكلمات من 12 وصفًا اصطناعيًا (4 لكل فئة) داخل DATA في triage.py، مع Laplace smoothing وتطبيع بعض الحروف العربية. تجمع درجات log-likelihood للكلمات المعروفة الفريدة وتطبع الدرجات عبر softmax. اقتراحات الفحص نصوص ثابتة منتقاة حسب الفئة؛ ليست توليدًا لغويًا ولا LLM.

يمتنع عن التصنيف عند أقل من كلمتين معروفتين، أو درجة أقل من 0.60، أو فارق بين أول فئتين أقل من 0.20. هذه حدود تجريبية غير معايرة. model_score **ليس احتمال صحة التشخيص**، ومراجعة الإنسان مطلوبة دائمًا. قد يخطئ بثقة، خصوصًا في النفي مثل «لا توجد مشكلة في التسجيل»، واللهجات والأعطال المختلطة وخارج نطاق التدريب.

## التقييم والحدود
6 حالات اصطناعية منفصلة عن نصوص التدريب لاختبار أولي، مع تشابه مفردات مقصود. ليست عينة مستقلة ممثلة لبلاغات حقيقية. evaluate.py يعرض المتوقع والفعلي وعدد النجاحات؛ tests تختبر أيضًا التطبيع والامتناع وتغير النتيجة عند تغيير التدريب. لا نستنتج دقة ميدانية من هذا التقييم الصغير.

استخدمه في مقابلة لشرح التدريب، التصنيف، الكلمات المطابقة، الامتناع، وأهمية مراجعة الفني. التوسع يتطلب بيانات مصرّحًا بها ومنزوعة الحساسية، تقييمًا مستقلًا وحالات نفي ولهجات وأعطال متعددة، ومراجعة مختص.

لا تدخل تسجيلات أو عناوين IP أو أسماء أو خرائط أو مواقع أو بيانات جهة عمل. لا ينفذ تغييرات أو أوامر أو إعادة تشغيل أو حذف تسجيلات؛ جميع الفحوص والإجراءات وفق صلاحيات المختص وسياسة الموقع. ليس نظام مراقبة إنتاجيًا أو إجراءً معتمدًا.

## الإصدار 2: فرز ملف بلاغات من Excel
احفظ الجدول CSV UTF-8 بفاصلة، بعمودين بالترتيب: ticket_id وdescription. استخدم أرقام LAB-001 فريدة وبيانات افتراضية فقط.
```sh
python batch.py examples/tickets.csv --out reports
```
افتح reports/report.html أو results.json. توجد معاينة افتراضية في demo. هذا استيراد CSV وليس اتصالًا مباشرًا أو إضافة داخل Excel، ولا يدعم xlsx. إذا ظهر الملف بعمود واحد في Excel استخدم استيراد النص واختر الفاصلة.

حدود الإدخال: 1 MB، 1–1000 بلاغ، وصف 1–1000 حرف بعد إزالة الفراغات الطرفية وفق عقد النموذج. يرفض الملف كاملًا عند خطأ في أي سجل، ولا يولد نتائج جزئية. exit 0 نجاح التصدير وليس صحة التشخيص؛ exit 2 خطأ. أسماء المخرجات ثابتة وتستبدل عند النجاح؛ قد تبقى تقارير قديمة بعد الفشل فلا تعتمد عليها. JSON وHTML يحفظان النتائج فقط دون الأوصاف الأصلية، وJSON لا يتضمن الكلمات المطابقة. الملف الأصلي يبقى كما هو. جميع التصنيفات تستلزم مراجعة بشرية، بما فيها الحالات التي لم يمتنع النموذج عن تصنيفها.

المثال يصنف 4 بلاغات إلى اتصال وتسجيل وصورة ومراجعة بشرية. الاختبارات العشرة تشمل الاستيراد، رفض التكرار والأعمدة الخاطئة، تهريب HTML، وحدود المصنف. لا تعني عدد الاختبارات أو نتائج المثال دقة ميدانية.

مرجع الاستيراد: [Python CSV](https://docs.python.org/3/library/csv.html).

## الإصدار 3: واجهة عربية محلية
```sh
python web_app.py
```
افتح http://127.0.0.1:8765 على الجهاز نفسه. اكتب وصفًا افتراضيًا ثم اضغط «اقتراح التصنيف». تظهر الفئة ودرجة غير معايرة وخطوات ثابتة ومطالبة بالمراجعة البشرية. توقف الخدمة بـ Ctrl+C.

واجهة متصفح وليست استضافة عامة؛ لا تفتح المنفذ أو تغير ربط localhost للاستخدام الإنتاجي. لا تدعم هذه النسخة Port Forwarding في Codespaces لأن فحص Host مقصور على localhost؛ استخدم CLI هناك. تستخدم POST حتى لا يظهر الوصف في عنوان الرابط، ولا تسجل طلبات أو تحفظ وصفًا في الخادم، لكن لا تضمن محو ذاكرة المتصفح أو الجهاز. لا توجد حسابات أو صلاحيات متعددة المستخدمين أو سجل تدقيق. Python http.server مخصص لهذا العرض المحلي فقط. لا تستخدم بيانات عمل حقيقية.

15 اختبارًا آليًا تشمل HTTP الحقيقي على منفذ محلي مؤقت، الاستجابة والتصنيف والمدخلات الفارغة والطويلة ورفض Origin خارجي وعدم إعادة عرض المدخلات كـ HTML. هذه اختبارات تشغيل وليست تقييمًا لدقة تشخيص ميدانية.

[مرجع Python HTTP server](https://docs.python.org/3/library/http.server.html).

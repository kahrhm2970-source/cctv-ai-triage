# CCTV AI Triage | مساعد فرز أوصاف أعطال الكاميرات
الحسين علي أبو طالب — Alhussin Ali Abutalib

مشروع تعليمي أُعد بمساعدة الذكاء الاصطناعي، يربط CCTV Operations والدعم الفني بتعلم الآلة. يصنف **الوصف النصي** إلى اتصال، تسجيل، جودة صورة، أو مراجعة بشرية. لا يحلل الفيديو أو يشخص السبب الجذري.

## تشغيل محلي بدون مفاتيح أو اشتراكات
Python 3.10+، المكتبة القياسية فقط:
```sh
python triage.py
python triage.py "فشل استرجاع التسجيلات القرص ممتلئ"
python evaluate.py
python -m unittest discover -s tests -v
```
يدخل المستخدم وصفًا افتراضيًا؛ الأداة لا تتصل بأي جهاز أو API ولا تحفظ المدخلات. استخدام وسيط سطر الأوامر قد يسجله في shell history؛ استعمل الإدخال التفاعلي مع بيانات افتراضية فقط.

## أين الذكاء الاصطناعي؟
مصنف Naive Bayes يتعلم تكرارات الكلمات من 12 وصفًا اصطناعيًا (4 لكل فئة) داخل DATA في triage.py، مع Laplace smoothing وتطبيع بعض الحروف العربية. تجمع درجات log-likelihood للكلمات المعروفة الفريدة وتطبع الدرجات عبر softmax. اقتراحات الفحص نصوص ثابتة منتقاة حسب الفئة؛ ليست توليدًا لغويًا ولا LLM.

يمتنع عن التصنيف عند أقل من كلمتين معروفتين، أو درجة أقل من 0.60، أو فارق بين أول فئتين أقل من 0.20. هذه حدود تجريبية غير معايرة. model_score **ليس احتمال صحة التشخيص**، ومراجعة الإنسان مطلوبة دائمًا. قد يخطئ بثقة، خصوصًا في النفي مثل «لا توجد مشكلة في التسجيل»، واللهجات والأعطال المختلطة وخارج نطاق التدريب.

## التقييم والحدود
6 حالات اصطناعية منفصلة عن نصوص التدريب لاختبار أولي، مع تشابه مفردات مقصود. ليست عينة مستقلة ممثلة لبلاغات حقيقية. evaluate.py يعرض المتوقع والفعلي وعدد النجاحات؛ tests تختبر أيضًا التطبيع والامتناع وتغير النتيجة عند تغيير التدريب. لا نستنتج دقة ميدانية من هذا التقييم الصغير.

استخدمه في مقابلة لشرح التدريب، التصنيف، الكلمات المطابقة، الامتناع، وأهمية مراجعة الفني. التوسع يتطلب بيانات مصرّحًا بها ومنزوعة الحساسية، تقييمًا مستقلًا وحالات نفي ولهجات وأعطال متعددة، ومراجعة مختص.

لا تدخل تسجيلات أو عناوين IP أو أسماء أو خرائط أو مواقع أو بيانات جهة عمل. لا ينفذ تغييرات أو أوامر أو إعادة تشغيل أو حذف تسجيلات؛ جميع الفحوص والإجراءات وفق صلاحيات المختص وسياسة الموقع. ليس نظام مراقبة إنتاجيًا أو إجراءً معتمدًا.
